# DESIGN DECISIONS — NAIFARM

| Decision ID | Topic | Choice & Rationale | Verification Criteria |
|---|---|---|---|
| `DD-01` | Color & Contrast Discipline | Preserve `DESIGN.md` Forest (`#245B3D`), Warm Rice (`#F5F3E9`), Deep Earth (`#25352B`), White (`#FFFFFF`), and Harvest Gold (`#D7A34D`) strictly paired with dark `#25352B` ink. Reject purple AI gradients, neon glows, and glassmorphism overlays. | Contrast >= 4.5:1 on body text, 0 purple gradients in CSS, Hallmark `sloplint` pass. |
| `DD-02` | Dual Seed Harmonization | Harmonize both the 12 Stitch exports (Chú Ba Minh Tân Triều pomelo + HTX Đồng Nai) AND the official De 3 seed (`Nhà vườn Ba Tư`, 2,5 ha Long Khánh, `P01` Chôm chôm Java `35.000 đ/kg` .. `P05` `120.000 đ/kg`, Minh Anh & Tuấn) into one coherent data layer without conflicting prices. | Same product ID always displays identical price & batch across `/`, `/products/[slug]`, `/cart`, `/farmer`, `/account/orders`. |
| `DD-03` | Typography & Vietnamese Clarity | Load `Be Vietnam Pro` (`400..700`) for functional UI/tables/controls and `Lora` (`500..700`) exclusively for editorial hero & orchard stories, with `vietnamese` subset and `line-height >= 1.3` headings / `1.6` body. | Zero clipped diacritics; tabular numerals `.tabular-nums` on prices/KPIs. |
| `DD-04` | Farmer U50+ Accessibility (W02) | `/farmer` and `/farmer/publish` enforce `18px` body text, `56px` primary buttons, `>=48px` inputs/tabs, plain Vietnamese copy, zero analytical clutter, and 3-step photo + voice/manual wizard. | Computed font-size `>=18px` and button height `>=56px` verified via Playwright. |
| `DD-05` | Honest Prototype & OCOP Labeling | Label all mock records (`Demo`), separate self-declared farm diaries (`Tự khai — chưa xác minh OCOP chính thức`) from co-op document checks (`Hồ sơ đã đối chiếu (Demo)`), and hide/disable live fake viewer counts on `/live`. | Zero fabricated certificates, zero false official emblems, explicit demo tags. |
| `DD-06` | Local Image Asset Integrity | Download all 65 `lh3.googleusercontent.com` assets from Stitch exports locally into `public/images/stitch/` to prevent URL expiry, offline demo failures, or broken `<img>` tags. | `65/65` local images verified; `naturalWidth > 0` across all routes in Playwright. |
| `DD-07` | Lightweight Lazy 3D | Render 1 interactive procedural 3D Bưởi Tân Triều viewer via React Three Fiber lazy-loaded on explicit user request (`"Xem mô hình 3D"` or `/learn`) with `dpr={[1, 1.5]}` and 2D fallback, rather than bloating initial bundle or using heavy unverified GLB downloads. | First load fast; 3D viewer mounts smoothly on demand with WebGL error fallback. |
| `DD-08` | Restrained Motion & Reduced Motion | Single primary animation system (`motion/react`) wrapped in `<MotionConfig reducedMotion="user">`; transitions `120ms–350ms` using `transform`/`opacity` only; no `transition: all`, no scroll hijacking. | Clean transitions; all flows work identically under `prefers-reduced-motion: reduce`. |
